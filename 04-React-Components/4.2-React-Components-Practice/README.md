# Task: Create a Basic React App with Two Components  

In this task, we will create a simple React app that displays a header and a content section using separate React components.  
We’ll also practice organizing our components in a clean folder structure.   
 
[![-----------------------------------------------------](https://github.com/Prabin128/React-Basics/blob/main/assets/line.png)](#JSX) 

**1. Create a New React App**  
**2. Set Up Folder Structure:**
- Inside the `src` folder, create a new folder called `components`.
- Inside the `components` folder, create two separate files:
    - `Header.jsx`
    - `Content.jsx`
**3. Create the Header Component:** 
- Open the `Header.jsx` file inside the components folder.

- Write a simple functional component that returns an `<h1>` element with the text **"Welcome to My React App!**".  

**4. Create the Content Component:**
- Open the `Content.jsx` file inside the components folder.

- Write a functional component that returns a simple `<p>` element with some text, like **"This is the content section of the app."**.  

**5. Use the Components in the App:**
- In the `src/App.jsx` file, import both `Header` and `Content` components.

- Inside the `App` component, render both the `Header` and `Content` components in the correct order.
    - Make sure Header is displayed first, followed by `Content`.  

**6. Bonus Challenge:**
- After completing the main task, try adding a third component called `Footer` that displays some simple text like **"This is the footer section."**
- Make sure to follow the same steps as before: create a `Footer.jsx` file, write the component, and import it into `App.jsx`.
