# Task: Build a Simple Blog App with React

1. Create a new React app.
2. Create an `App.jsx` component.
3. Create a `Navbar.jsx` component that renders a `<nav>` element with a list of links to different sections of the website (e.g., Home, About, Contact).
4. Create a `Post.jsx` component that displays a blog post. It should have:
- An `<h2>` for the blog post title.
- A `<p>` for the blog post content.
- A `<small>` tag displaying the author's name and the publish date.
5. Create a `Sidebar.jsx` component that renders a list of recent blog posts, with each post as a clickable link to view its details.
6. Create a `Footer.jsx` component that displays a copyright notice and the current year dynamically.
- Display a copyright notice and the current year dynamically using JavaScript's Date().getFullYear() method.
7. Make sure to style the website like a clean, modern blog, using CSS classes from the provided styles.css file.
